# Слой

Учебный интернет-магазин керамики. Контрольная работа №1 по дисциплине «Фронтенд и бэкенд разработка». Тема работы — «HTML и CSS: разработка многостраничного сайта».

Озеров Максим Дмитриевич, группа ЭФБО-11-25.

[Открыть сайт на GitHub Pages](https://proxima145.github.io/kr1-html-css-shop/)

## Как посмотреть

Открой ссылку выше или скачай репозиторий и открой `index.html` в браузере. Устанавливать зависимости не нужно.

## Страницы и файлы

| Файл | Что в нём |
| --- | --- |
| `index.html` | Главная, популярные изделия и преимущества |
| `catalog.html` | Каталог с категориями и фильтром |
| `product.html` | Карточки изделий, таблицы характеристик и окно доставки |
| `order.html` | Форма заявки и экран после проверки полей |
| `contacts.html` | Контакты учебной мастерской и ссылка на заявку |
| `care.html` | Советы по уходу и ответы на частые вопросы |
| `css/style.css` | Общие стили всех страниц |
| `js/main.js` | Открытие окна доставки |
| `images/` | Фото изделий в WebP |
| `.gitignore` | Исключения для файлов редактора и системы |

## Технологии

HTML5, CSS, JavaScript для открытия `dialog`, Git и GitHub Pages. Навигация и группы кнопок собраны на Flexbox, сетка каталога и раскладки страниц — на CSS Grid. Названия классов следуют БЭМ. Палитра, отступы и скругления вынесены в CSS-переменные.

## Доработки

- Фильтр каталога на радиокнопках и CSS. Ссылки ведут к любому из шести изделий на странице товара.
- Отдельная страница ухода с раскрывающимися ответами, хлебные крошки и кнопка «Наверх».
- В карточках есть размеры и цена, а таблицы и фотографии оформлены одинаково по всему каталогу.
- В форме работают подписи, обязательные поля, проверка почты и согласие. Данные остаются в браузере. В меню и форме виден фокус с клавиатуры.
- Окно доставки открывается кнопкой и закрывается крестиком или клавишей Esc. Фотографии сохранены локально в WebP.
